# Ritmika — магазин базовой одежды на Flask

Полностью рабочий интернет-магазин одежды: каталог с фильтрами, серверная корзина,
оформление заказов с записью в базу, аккаунты покупателей и админ-панель.

## Возможности

- Каталог из 12 моделей с фильтрацией по категориям и сортировкой по цене;
- Карточка товара с выбором размера и похожими вещами;
- Серверная корзина (сессия): изменение количества, удаление, бесплатная доставка от 10 000 ₽;
- Оформление заказа с валидацией: заказ и позиции сохраняются в SQLite, покупатель
  получает номер заказа на отдельной странице;
- Аккаунты: регистрация и вход (пароли только в виде хешей), личный кабинет
  с историей заказов;
- Админ-панель со списком всех заказов (только для пользователей с флагом is_admin);
- Подписка на рассылку с фиксацией согласия;
- Правовые документы по 152-ФЗ: Пользовательское соглашение и Политика конфиденциальности.

## Быстрый старт

```bash
pip install -r requirements.txt
python run.py
```

Сайт откроется на http://127.0.0.1:5000. База SQLite создастся сама
в `instance/ritmika.db`, как и секретный ключ сессий.

Администратор создаётся командой:

```bash
flask --app run.py create-admin admin@example.com пароль-минимум-8
```

После входа под этим аккаунтом появится ссылка «Админ».

## Структура

```
ritmika-site/
├── run.py                  # точка входа
├── requirements.txt
├── pyproject.toml          # настройки ruff и pytest
├── ritmika/
│   ├── __init__.py         # фабрика приложения, CSRF, фильтр цен
│   ├── db.py               # SQLite: схема, соединение на запрос
│   ├── products.py         # данные каталога (12 моделей)
│   ├── auth.py             # регистрация, вход, кабинет, админка
│   ├── shop.py             # каталог, товар, корзина, заказ, подписка
│   ├── templates/          # Jinja2: базовый шаблон + страницы
│   └── static/             # стили, скрипт, фотографии
└── tests/                  # pytest: маршруты, корзина, заказы, доступ
```

## Тесты и проверки

```bash
python -m pytest

python -m bandit -r ritmika -ll
```

## Безопасность

- CSRF-токены во всех формах (сверка на сервере на каждом POST);
- Пароли хранятся только в виде хешей (werkzeug);
- Цены и состав заказа всегда пересчитываются на сервере — данные из формы
  не доверяются;
- Защита от open redirect в возвратах после добавления в корзину;
- Доступ к кабинетам и админке проверяется на сервере;
- Секретный ключ сессий лежит в `instance/` и не попадает в git.
